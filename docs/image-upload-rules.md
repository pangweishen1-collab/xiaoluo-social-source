# 全站图片上传规则

所有新增图片上传入口必须复用 `shared/image-upload.mjs` 中的 `IMAGE_UPLOAD_RULES`，不得在组件内另写格式、尺寸或体积限制。

- 输入格式：JPEG、PNG、WebP。
- 输出格式：WebP（`image/webp`、`.webp`）。
- 最大边长：1920px；必要时逐级缩小，最低尝试到 480px。
- 编码质量：依次尝试 0.82、0.70、0.58、0.46。
- 存储上限：压缩后不超过 3MB。
- 客户端负责缩放与转码；服务端重新检查 Data URL、体积和 `RIFF/WEBP` 文件签名。
- Cloudflare R2 对合规文件使用一年不可变缓存。

目前人才市场图片入口已经执行此规则。以后新增文章封面、公司 Logo 或其他上传入口时，应调用同一套规则，而不是复制实现。
