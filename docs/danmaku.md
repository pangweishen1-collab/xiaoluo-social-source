# 首页弹幕（本地）

展示更新：弹幕层按文档首屏高度定位，不跟随滚动；14px 字号，每条播放结束后退出队列，本次页面浏览期间不重播，重新加载页面可重新播放。日报正文链接使用蓝色。

首页专属入口、原生 dialog、昵称 16 字和留言 80 字上限。React 文本渲染，不执行 HTML。3 条轨道每 22 秒轮换，每 30 秒读取最近 60 条。隐藏开关与减少动态效果适配。数据库是权威存储，浏览器关闭后留言仍保留。

本地已应用 drizzle/0001_first_the_order.sql。没有修改生产数据库或发布。

正式发布前需应用该迁移到生产，增加管理员隐藏/删除留言及垃圾内容治理。当前是匿名直接展示模式，服务器按 IP 的 SHA-256 标识限制 30 秒一次，不保存原始 IP；这不是完整的防机器人机制，也不验证昵称身份。无 CF IP 的本地请求共用一个发送频率桶。
