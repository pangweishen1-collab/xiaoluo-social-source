# 网站基建检查 · 2026-09-15

范围：现有本地 checkout 的源码、类型、构建、测试、依赖、公共接口和权限边界。没有部署，没有改线上数据，没有执行浏览器点击/截图验收，也没有进行攻击性压力测试。本报告不是安全认证。

## 已修复

1. **文章缓存影响可用性**：浏览器存储被禁用、写满或数据损坏时，仍可请求文章；缓存超过 30 秒不直接显示。新增存储失败和过期回归测试。
2. **后台网络异常**：文章保存用 finally 恢复按钮，保留草稿并提示先确认保存结果；删除检查响应，不再把失败当成功。管理列表也显示错误。
3. **导航状态**：导航切换同步 URL，浏览器返回继续按 URL 恢复页面；重复点击当前页面不追加历史。
4. **跨站写入**：公共 Worker 和独立文章处理器统一拒绝异源 Origin 或 cross-site 写请求；管理员权限验证保留，非浏览器同源工具调用不受影响。
5. **Logo 更新缓存**：上传图片 URL 加更新时间版本，读取采用重新验证，不再对固定可覆盖地址声明永久 immutable 缓存。
6. **类型基础设施**：分开浏览器/Worker 类型检查，使用 Wrangler 生成运行时类型；补齐矩阵选择空值、人才字段和闲时调度类型，去掉已停用资源网络页面中未定义头像变量的引用。
7. **回归检查**：按已确认需求更新导航、缓存读取和 3:4 封面测试，保留功能断言；新增缓存与跨站写入测试。
8. **提交保护**：忽略 .dev.vars 及其变体、TypeScript 临时构建信息；没有删除用户文件。

## 剩余风险与顺序

### 发布前优先处理

- **依赖安全**：完整依赖树包含 react-server-dom-webpack、vite、sharp、undici、ws 等告警。部分声明为开发依赖的模块参与生产构建，不能将其全部视为仅影响本机。需要沿依赖路径分批升级和兼容性回归；未执行批量强制升级。审计数量是包管理器当次结果，不等于线上可利用漏洞数。
- **管理员凭据配置**：主 Worker 仍有固定管理员凭据校验配置。应迁移为部署环境 secret 并轮换；本轮没有擅自更换密码或让当前管理员失去登录权限。缺少登录限流也需一起处理。
- **数据库迁移**：文章、矩阵等旧模块仍在请求初始化中 CREATE/ALTER 表。应先核对已应用迁移与数据库实际结构，再逐步交给版本化迁移；不能直接删除初始化代码或重跑未知历史迁移。site_content_updates 的既有发布前迁移要求仍有效。

### 后续工程整治

- **ESLint 存量问题**：仍有 React effect 状态更新、链接与可访问性、未使用符号等错误/警告。没有通过关闭规则来伪造全绿。建议逐模块修复，而非整站机械改写。
- **开发数据源分裂**：vite.config.ts 默认将文章及人才公共 GET 代理到线上，但管理写入本地，矩阵读取也为本地。可能出现后台保存成功而公开列表仍是线上版本。用于编辑验收时，以 XIAOLUO_REMOTE_ARTICLES=0 启动本地数据模式，并事先准备本地数据；不要将本地测试操作发到线上。
- **缓存一致性**：公共列表 30 秒缓存是短时优化，不是跨标签页实时同步；当前写入清理本标签页缓存。跨标签页即时同步、弱网超时和长请求取消仍可加强。
- **运维验收**：尚未验证线上部署、回滚演练、数据库备份恢复、R2 孤立资源回收、访问峰值压力，以及手机浏览器交互。没有这些证据时不应宣称“全面安全”或“可直接上线”。

结论：本轮修复了已确认的稳定性与请求边界问题，并建立可重复检查入口；类型、构建、90 项测试通过。依赖安全、凭据配置、迁移治理和 ESLint 仍需继续处理，当前不建议未经后续验收直接发布。
